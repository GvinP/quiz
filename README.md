# quiz

Тренажёр по вопросам для подготовки к техническим собеседованиям по React Native.
Открывается как Telegram Mini App, работает и в обычном браузере.

## Структура

```
/data       # банк вопросов, по файлу на тему
/docs       # quiz-schema.md — контракт данных
/scripts    # валидация данных
/src        # приложение (Vite + React + TypeScript)
```

## Разработка

```sh
npm install
npm run dev        # http://localhost:5173/quiz/
npm test           # тесты: кодек прогресса, Лейтнер, очереди режимов
npm run check      # валидация + типы + тесты + сборка, то же самое делает CI
```

## Добавление вопросов

Новый файл в `/data` подхватывается без правок кода: темы находятся глобом на
сборке. Имя файла должно совпадать с полем `topic` внутри него.

Схема вопроса и правила изменения контента — в [docs/quiz-schema.md](docs/quiz-schema.md).
Перед коммитом стоит прогнать `npm run validate`: тот же скрипт стоит в CI и
уронит сборку, если в данных ошибка.

## Деплой

Пуш в `main` собирает и публикует приложение на GitHub Pages.
