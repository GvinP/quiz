# quiz

Тренажёр по вопросам для подготовки к техническим собеседованиям по React Native.
Открывается как Telegram Mini App, работает и в обычном браузере.

## Структура

```
/data/ru    # банк вопросов, по файлу на тему + topics.json с порядком и группами
/data/en    # перевод: те же id, те же correct, сверяется валидатором
/docs       # quiz-schema.md — контракт данных
/scripts    # валидация данных и экспорт банка для бота
/src        # приложение (Vite + React + TypeScript)
/bot        # бот-интервьюер на Google Apps Script — см. bot/README.md
```

## Режимы

1. **Квиз** — вопросы выбранной темы подряд, в конце результат и список ошибок
2. **Повторение** — вперемешку из всех тем, только то, что пора повторить по Лейтнеру
3. **Работа над ошибками** — где доля верных ответов ниже 60% при двух и более показах

Открытые вопросы (`type: "open"`) отвечаются вслух: «Показать ответ» в один тап,
дальше самооценка «знал / частично / не знал», которая идёт в тот же прогресс.

Прерванная сессия сохраняется: закрыл приложение на середине темы — на главном
экране появится «Продолжить» с того же вопроса.

Язык переключается на главном экране. Прогресс у каждого языка свой: пройти
тему по-русски и потом заново по-английски — это два независимых счёта.

Прогресс хранится в `Telegram.WebApp.CloudStorage`, в обычном браузере — в
`localStorage`. Формат и схема ключей описаны в [docs/quiz-schema.md](docs/quiz-schema.md).

## Бот-интервьюер

Раз в день присылает в Telegram вопрос из этого же банка, принимает ответ
текстом или голосом, проверяет через Gemini и задаёт уточняющий вопрос. Слабые
темы спрашивает чаще. `npm run build` дополнительно публикует банк для бота в
`dist/bot/<язык>.json`. Установка — в [bot/README.md](bot/README.md).

## Разработка

```sh
npm install
npm run dev        # http://localhost:5173/quiz/
npm test           # тесты: кодек прогресса, Лейтнер, очереди режимов
npm run check      # валидация + типы + тесты + сборка, то же самое делает CI
```

## Добавление вопросов

Новый файл в `data/<язык>` подхватывается без правок кода: темы находятся глобом на
сборке. Имя файла должно совпадать с полем `topic` внутри него.

Порядок и группировка на экране выбора задаются необязательным
`data/topics.json`. Темы, которой в нём нет, это не мешает — она просто встанет
в конец списка.

Схема вопроса и правила изменения контента — в [docs/quiz-schema.md](docs/quiz-schema.md).
Перед коммитом стоит прогнать `npm run validate`: тот же скрипт стоит в CI и
уронит сборку, если в данных ошибка.
