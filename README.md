# quiz

Контент для квиза по подготовке к собеседованию.

## Структура

```
/data
  topics.json           # реестр тем
  rn-architecture.json
  rn-performance.json
/docs
  quiz-schema.md        # контракт данных: схема вопроса, прогресс, правила добавления
```

Схема вопросов и правила добавления контента описаны в [docs/quiz-schema.md](docs/quiz-schema.md).
Приложение не знает ничего о конкретных вопросах — только о схеме.
