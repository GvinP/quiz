# Бот-интервьюер

Telegram-бот, который раз в день задаёт вопрос из банка квиза, принимает ответ
текстом или голосом, проверяет его через Gemini и задаёт уточняющий вопрос, как
на живом интервью. Работает на Google Apps Script: webhook в `doPost`,
состояние и история хранятся в Google Таблице.

Кнопку Mini App, настроенную в BotFather, бот не трогает: он вызывает только
`setWebhook` и `setMyCommands`.

## Как это устроено

```
GitHub Pages ── /quiz/bot/ru.json, en.json ──┐   (scripts/export-bot.mjs при сборке)
                                             ▼
Telegram ── webhook ──▶ Apps Script (doPost) ──▶ Gemini API
                              │
                              ▼
                       Google Таблица: State · History · Cards
```

- **Вопросы.** `npm run build` после сборки приложения пишет `dist/bot/<язык>.json`,
  и Pages публикует их вместе с приложением. Вопросы с вариантами бот задаёт как
  открытые: правильные варианты вместе с `explanation` становятся эталоном.
  Если формулировка без вариантов не имеет смысла, вместо неё бот берёт поле
  `openQuestion` (см. [контракт данных](../docs/quiz-schema.md)).
- **Проверка.** По основному ответу Gemini присылает оценку от 1 до 10, что
  упущено, короткий эталон и один уточняющий вопрос. Ответ на уточнение
  проверяется коротко, после этого вопрос закрыт. В режиме EN бот дополнительно
  правит языковые ошибки. Голосовое уходит в модель как аудио, без отдельного
  распознавания.
- **Повторение.** Работает по Лейтнеру, как в приложении: интервалы 0/1/3/7/21 дней.
  - Оценка 8–10 поднимает вопрос на коробку выше.
  - Оценка 5–7 оставляет на месте.
  - Оценка 1–4 сбрасывает в первую коробку.

  Тема выбирается с весом `11 − средний балл`, поэтому слабые темы выпадают
  чаще. Внутри темы сначала идёт то, что пора повторить, потом новое. Прогресс
  общий для RU и EN.
- **Дубли.** `update_id` запоминается в `CacheService` на 6 часов до вызова
  Gemini, поэтому повтор, который Telegram прислал во время проверки,
  отбрасывается сразу.

Команды: `/question`, `/skip`, `/lang`, `/stats`, `/help`.

## Установка

### 1. Банк вопросов на Pages

Смёржи ветку в `main`. Deploy соберёт сайт, и файлы появятся по адресам:

- https://gvinp.github.io/quiz/bot/ru.json
- https://gvinp.github.io/quiz/bot/en.json

Открой первый в браузере: должен показаться JSON.

### 2. Ключи

- **Токен бота** — у @BotFather (`/mybots` → бот → API Token). Бот тот же, что с Mini App.
- **Ключ Gemini** — https://aistudio.google.com/apikey → Create API key.
  Бесплатного тарифа одному человеку хватает с запасом. ⚠️ В бесплатном тарифе
  Google использует запросы для улучшения своих продуктов.

### 3. Таблица и скрипт

1. Создай пустую Google Таблицу, например «Interview bot».
2. В ней открой **Расширения → Apps Script**. Скрипт будет привязан к этой таблице.
3. **Project Settings** (шестерёнка):
   - **Time zone** поставь `(GMT+03:00) Moscow`. Это пояс журналов, сам бот берёт пояс из `TIMEZONE`.

Дальше выбери один из двух способов загрузки кода.

**Вариант А — вставить один файл.** Открой https://gvinp.github.io/quiz/bot/Code.js:
это все файлы `bot/src` в одном скрипте, его собирает каждый деплой Pages.
Выдели всё, скопируй и вставь в `Code.gs` вместо его содержимого, затем
нажми 💾. Манифест `appsscript.json` при этом трогать не нужно: V8 включён
по умолчанию, а доступ к web app задаётся в окне деплоя (шаг 5). После
обновления бота в репозитории повтори вставку и обнови деплой.

**Вариант Б — через clasp.**

```sh
npm install -g @google/clasp
clasp login
# один раз включи Apps Script API: https://script.google.com/home/usersettings
cd bot
cp .clasp.json.example .clasp.json   # впиши Script ID из Project Settings → IDs
clasp push                           # отправляет bot/src в проект
```

После правок кода повторяй `clasp push`, а потом обновляй деплой (шаг 5).

### 4. Script Properties

**Project Settings → Script Properties → Add script property:**

| Ключ | Значение |
|---|---|
| `TELEGRAM_TOKEN` | токен из BotFather |
| `GEMINI_API_KEY` | ключ из AI Studio |
| `CHAT_ID` | твой chat_id (как узнать — ниже) |
| `WEBHOOK_URL` | URL web app (появится на шаге 5) |

Необязательные ключи `setup()` заполнит сам:

| Ключ | По умолчанию | |
|---|---|---|
| `TIMEZONE` | `Europe/Moscow` | любой IANA-пояс |
| `DAILY_TIME` | `11:00` | время вопроса дня, `ЧЧ:ММ` |
| `GEMINI_MODEL` | `gemini-3.8-flash` | |
| `GEMINI_THINKING` | `low` | `low` / `medium` / `high`, для моделей до Gemini 3 — `off` |
| `QUESTIONS_URL` | `https://gvinp.github.io/quiz/bot/` | |
| `WEBHOOK_SECRET` | случайная строка | секрет в URL webhook |
| `SHEET_ID` | — | только если скрипт не привязан к таблице |

**Как узнать `CHAT_ID`.** Напиши что-нибудь @userinfobot, он ответит твоим id.
Другой способ: оставь `CHAT_ID` пустым, пройди шаги 5–6 и напиши своему боту.
Пока `CHAT_ID` не задан, бот отвечает только строкой `chat_id: …`. Как только
впишешь id, бот перестаёт отвечать всем остальным.

### 5. Деплой web app

1. **Deploy → New deployment → ⚙ Select type → Web app.**
2. Настройки:
   - **Execute as:** Me;
   - **Who has access:** Anyone (Telegram стучится без авторизации; от чужих защищают секрет в URL и проверка `CHAT_ID`).
3. Нажми **Deploy**. Google попросит доступы (таблица, внешние запросы, триггеры), разреши.
4. Скопируй **Web app URL** (оканчивается на `/exec`) в Script Property `WEBHOOK_URL`.

> После правок кода **не создавай новый деплой**: у него будет новый URL.
> Обновляй существующий: **Deploy → Manage deployments → ✏️ → Version: New version → Deploy**.

### 6. Webhook, команды, триггер

В редакторе выбери функцию **`setup`** и нажми **Run ▶**. Она:

- создаст листы `State`, `History`, `Cards`;
- заполнит необязательные Properties;
- зарегистрирует команды (`setMyCommands`);
- поставит ежедневный триггер на `DAILY_TIME` в `TIMEZONE`;
- поставит webhook и выведет в журнал `getWebhookInfo`.

### 7. Проверка

1. **Журнал `setup`:** в выводе `getWebhookInfo` поле `last_error_message` должно отсутствовать. Позже его можно проверить функцией `webhookInfo`.
2. **`testGemini`:** в журнале должен появиться JSON с оценкой. Так проверяются ключ и модель.
3. **В Telegram:** `/question` → ответь → получи разбор и уточнение → ответь на уточнение.
4. **`testDaily`:** присылает вопрос так же, как утренний триггер.

## Если что-то не так

- **В `webhookInfo` висит `Wrong response from the webhook: 302…`.** Иногда
  Apps Script отвечает на POST редиректом, а Telegram по нему не идёт и повторяет
  update. Дубли бот отсекает, но очередь может копиться. Запусти **`enablePolling`**:
  webhook снимется, и бот будет забирать сообщения через `getUpdates` раз в минуту
  (ответ придёт с задержкой до минуты). Вернуть webhook можно функцией `enableWebhook`.
- **Сменить время или пояс.** Поменяй `DAILY_TIME` или `TIMEZONE` и запусти
  `setupDailyTrigger`. Apps Script срабатывает с разбросом до ±15 минут.
- **Бот молчит.** Открой **Executions** в редакторе: ошибки каждого вызова
  `doPost` видны там. Частые причины: не обновлён деплой после правки кода или
  опечатка в `CHAT_ID`.
- **Gemini отвечает 400.** Проверь `GEMINI_MODEL`. Для моделей до Gemini 3
  поставь `GEMINI_THINKING` = `off`.

## Разработка

Чистая логика (выбор вопроса, Лейтнер, разметка, тексты, промпты) лежит в
`src/Logic.js` и `src/Prompts.js`, без вызовов Apps Script. Её проверяют тесты
`test/bot.test.ts`, они входят в `npm test` и CI. Остальные файлы — тонкие
обёртки над `UrlFetchApp`, `SpreadsheetApp` и Bot API.
